ALLOWED VERDICTS
For every QA item return exactly one of: "yes" = sufficient visible evidence shows that the requirement is satisfied; "no" = sufficient visible evidence shows that the requirement is violated; "unjudgeable" = the generated video does not provide enough visible evidence to decide reliably because of occlusion, severe motion blur, object disappearance, relevant content leaving the frame, severe generation artifacts, insufficient temporal visibility, or another visibility failure. PRECONDITIONED / ORDERING QA RULE
Some QA items ask whether a relationship holds between two events (for example, whether event A occurs before event B, or whether some action or state is associated with a later action). Such a QA implicitly presupposes that the relevant events actually occur. Judge it as follows: (1) if all presupposed events are visibly present, decide "yes" or "no" from the temporal order actually shown in the video, never assumed from the intended order; (2) if any presupposed event is definitively absent from the video, because the video clearly never shows it (for example, a QA asking whether scalpel transfer precedes scraping when scraping never occurs at all), return "no", since the required relationship cannot hold; do NOT return "unjudgeable" here, because the absence is decisive rather than a visibility failure, and state in the rationale which presupposed event is absent; (3) if you cannot determine whether a presupposed event occurred (occlusion, content leaving the frame, severe artifacts, insufficient temporal visibility), return "unjudgeable", and never claim absence when occurrence is merely unverified. Apply this rule only to QA items that explicitly ask about a relationship between two task events; do not use it to fail unrelated Scene Consistency, Object Consistency, or other items merely because a related action is missing.

ATOMIC QA RULE
Each QA item tests one atomic requirement. Judge only the requirement explicitly asked in that QA. Do not penalize an item for an unrelated failure that belongs to another QA or another dimension. Example: for "Does the pipette remain a single identifiable object throughout the video?", if the pipette keeps its identity but the hand motion is physically implausible, this QA should still be "yes"; the physical problem belongs to a Physical Plausibility QA. Do not allow one visible defect to cause unrelated QA items to fail.
